 Mentor Personal Website

A responsive personal website designed for an educator, mentor, and speaker. The website presents her professional background, highlights her work in education and mentorship, and provides visitors with convenient ways to connect with her.

📌 About the Project

This project is a professional personal website created to establish an online presence for an educator and mentor. It introduces her professional identity, showcases her experience and areas of interest, and allows visitors to contact her.

The website features a clean, modern design with responsive layouts for different screen sizes.

✨ Features

- Responsive Design: Adapts to mobile phones, tablets, and desktop computers.
- Professional Profile: Presents the educator's background and professional identity.
- Biography and Experience: Highlights relevant information about her career and work.
- Contact Form: Allows visitors to send inquiries through an integrated Formspree service.
- WhatsApp Integration: Provides a convenient way for visitors to initiate conversations.
- Contact Information: Displays relevant contact details and location.
- Social Media Links: Provides access to available social media profiles.
- Interactive Elements: Uses JavaScript to support website functionality.
- Modern User Interface: Features a professional layout, typography, and visual styling.

 🛠️ Technologies Used

- HTML5 — structures the website's content.
- CSS3 — handles styling, layout, animations, and responsive design.
- JavaScript — adds interactive functionality.
- Formspree — processes contact form submissions.

 📱 Responsive Design

The website is designed to work across different screen sizes, including:

- Laptop screens
- Desktop computers
